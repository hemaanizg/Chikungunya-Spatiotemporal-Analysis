2. Raw-data provenance manifest: SINAN extraction dates, 2026 cut-off, IBGE population dataset IDs/tables, geobr boundary version, original URLs, and checksums.
3. A checked sequence of inputs → intermediates → figures/tables linking paper results to exact source and commit.
4. An independently tested fresh clone: File 01, File 02, saved-fit recovery, all required downstream scoring and plotting. **This has not been confirmed yet.**

## Upload guidance

- **Small public CSV tables and figure files:** put in appropriately named versioned `outputs/` directories when checked and final.
- **Large INLA RDS models:** consider Zenodo or a GitHub Release asset with DOI/checksums; avoid forcing them into regular Git history.
- **Raw SINAN microdata:** existing historical files are already publicly tracked; do not automatically add a potentially large or provisional 2026 extract without confirming permitted redistribution and de-identification.
- **`.gitignore` currently ignores `*.rds` and `*.adj`:** an intentional source-only default. If you choose to version smaller RDS/adjacency artifacts, review that rule or deliberately force-add them. GitHub’s web uploader is a separate workflow.
- Directories such as `outputs/` or `data/processed/` are recommendations, not claims that those results have already been uploaded.

The population panel and most analysis files share relative paths. **Keep the working directory at `analysis/` after the reorganization** unless you have intentionally refactored these paths.
